# Imagens

As imagens do ViceHub para publicar. Todas em 1600×900 — a medida que o
X usa para uma imagem única — e a mesma coisa em dobro, para quem as
abre em tamanho real.

| Ficheiro | O que é |
|---|---|
| `vicehub-system-1600x900.png` | O que está construído: o servidor a reportar-se, os módulos da API com os endpoints de cada um, o ecrã, e a base de dados por baixo |
| `vicehub-card-1600x900.png` | O cartão de anúncio |
| `*-3200x1800.png` | As mesmas, em dobro |

São geradas a partir do HTML no [kit de imagens](https://claude.ai/code/artifact/026c5200-a130-4275-af87-12ebab2cd3f7),
com as fontes do produto (Chakra Petch, Inter, JetBrains Mono) e as
cores do `theme.css`. Os números que aparecem na primeira foram contados
contra o `main` no dia em que foi feita, e não escritos à mão.
