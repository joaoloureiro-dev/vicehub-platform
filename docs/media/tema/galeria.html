ViceHub at night

Way in

/

Landing

What the platform is, plus what is happening in the game and across ViceHub right now.

/entrar

Sign in

Email and password, or Discord and Google. An anti-robot check sits on every door.

/registo

Create account

Playing is free and stays free. What is paid for is running a community.

/premium

Pricing

The plan belongs to a crew or a server, never to a person.

/termos

Terms

Written from what the code actually does, and tied to it by a test.

/privacidade

Privacy

No analytics. Two cookies, both strictly necessary, which is why there is no banner.

Finding people

Crew directory

Who is playing, and who is looking for people.

/servidores

Sorted by where people actually are, from hour-by-hour history.

/recrutamento

Recruitment board

Crews that are open, with how long each notice has been up.

/forum

Forum

A crew

Members, roles, level, and what has already been decided about whom.

A name and a tag. The tag is claimed, not typed twice.

Running a server

A server

Who plays here, the activity strip, and the keys that feed it.

/servidores/novo

New server

A name and a region. The API key comes after.

/servidores/:id/tesouraria

A server's treasury

The same four balances, for the people who run the place.

/servidores/:id/eventos

A server's events

Everything the crews on this server have planned.

A server's market

In-game currency only. Selling anything for real money is against the Terms.

/mercado/:id

A listing

A price, a category, and a seller with a rating that came from real sales.

Talking

/mercado/conversas

Conversations

Every thread about something you are buying or selling.

/mercado/conversas/:id

One conversation

Buyer and seller, about one listing, with the listing still in view.

/avisos

Notifications

Replies, messages and reviews. It refreshes while you are here, not only on F5.

/moderacao

Report queue

One queue for everywhere the public writes: topics, replies, listings, messages, reviews.
